Training Diagnostics & Behavioral Analysis

Qwen3-0.6B — Distillation Diagnostics

Fully Converged (5 Epochs): Trained across 120 steps with effective batch size 16.
Rejection Sampling Filter: Filtered 2,840 raw Gemini trajectories to the top 20.8% with Recall@20 > 0, preventing the student from imitating failed paths.
Healthy Generalization: Final eval loss = 0.368, token accuracy = 91.4% on validation trajectories.
Multi-Hop Transfer: Learns to call search_in_neighborhood (from Gemini's 30% exploration distribution) rather than collapsing to 1-hop shortcuts.

Qwen3-4B — Oracle SFT Diagnostics

Rapid Format Convergence: Reached 0.065 train loss and 98.4% token accuracy within 111 steps.
Shortcut Learning Pathology: Memorized the rigid 1-hop pattern of Oracle shortest paths (search_in_graph → add_to_answer → finish).
0% Neighborhood Search: Never invoked search_in_neighborhood in 20/20 test trajectories because Oracle training data lacked multi-hop explorations.
Key Lesson: Token imitation accuracy ≠ task-level graph reasoning ability.
